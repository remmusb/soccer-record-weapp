## 启动步骤

### 第一步：安装 HBuilderX

1. 下载 [HBuilderX](https://www.dcloud.io/hbuilderx.html)（uni-app 官方IDE）
2. 安装后打开

### 第二步：打开项目

1. 在 HBuilderX 中点击「文件」→「打开目录」
2. 选择 `soccer-record-weapp` 文件夹

### 第三步：配置小程序AppID

编辑 `manifest.json`：

```json
{
  "mp-weixin": {
    "appid": "你的小程序AppID",
    ...
  }
}
```

把你的小程序 AppID 填进去（在微信公众平台「开发」→「开发设置」里找到）。

### 第四步：开启微信云开发

1. 打开微信开发者工具
2. 登录你的小程序账号
3. 点击「云开发」按钮（在顶部工具栏）
4. 按提示创建云开发环境
5. 记录**环境ID**（如 `soccer-record-xxx`）

### 第五步：配置云开发环境ID

编辑 `App.vue`：

```javascript
wx.cloud.init({
  env: '你的云环境ID',  // ← 替换这里
  traceUser: true
})
```

### 第六步：创建数据库集合

在微信开发者工具 → 云开发控制台 → 数据库：

创建以下集合：

| 集合名 | 说明 |
|--------|------|
| `players` | 球员资料 |
| `matches` | 场次数据 |
| `settings` | 全局设置 |

**创建后添加索引（重要）：**

- `matches` 集合：
  - `date`（降序）
  - `status`（升序）
  - `ownerId`（升序）
  - `assistantId`（升序）

- `players` 集合：
  - `stats.rating`（降序）
  - `nickname`（升序）

### 第七步：部署云函数

在微信开发者工具中：

1. 右键 `cloudfunctions/login` →「创建并部署：云端安装依赖」
2. 右键 `cloudfunctions/recalculateStats` →「创建并部署：云端安装依赖」

### 第八步：添加静态图标

在 `static/` 目录下添加 8 张图标（建议尺寸 81x81px，PNG格式）：

| 文件名 | 用途 |
|--------|------|
| `tab-match.png` | 场次未选中 |
| `tab-match-active.png` | 场次选中 |
| `tab-players.png` | 球员未选中 |
| `tab-players-active.png` | 球员选中 |
| `tab-stats.png` | 统计未选中 |
| `tab-stats-active.png` | 统计选中 |
| `tab-settings.png` | 设置未选中 |
| `tab-settings-active.png` | 设置选中 |

可以先用简单的图标，后续替换。

### 第九步：运行预览

1. 在 HBuilderX 中点击「运行」→「运行到小程序模拟器」→「微信开发者工具」
2. 首次运行会自动编译并打开微信开发者工具
3. 在微信开发者工具中点击「预览」→ 扫码在真机上测试

## 首次使用流程

1. 打开小程序，先添加管理员（「设置」tab → 管理员管理）
2. 添加球员（「球员」tab → 添加），设置初始评分
3. 创建场次（「场次」tab → 创建），指定场主/护法、截图截止时间
4. 点击场次进入详情，报名（需要上传抽场截图）
5. 报名完成后，自动分队
6. 开始比赛 → 记录赛况 → 结束比赛
7. **赛后评分**：参赛队员互评 + 管理员评分
8. 统计自动更新

## 关键特性说明

### 📸 截图上传报名
- 报名必须上传抽场截图（聊天记录、付款截图等）
- 上传后状态变为「已确认」，否则为「待截图」
- 只有「已确认」的报名才算有效出场

### 👑 场主与护法
- 创建场次时指定场主和护法（组织角色）
- 场主/护法在报名列表中有特殊徽章
- 球员主页显示场主/护法次数和组织历史

### 👔 管理员系统
- 管理员独立于场主/护法，由admin指定（最多10人）
- 管理员可以给所有球员打分
- 在「设置」tab 管理管理员列表

### ⭐ 评分系统
综合评分 = 队友互评 × 50% + 管理员评分 × 30% + 比赛表现 × 20%

- **队友互评**：赛后参赛队员互相打分（1-10分）
- **管理员评分**：管理员给球员打分（1-10分）
- **比赛表现**：
  - 前场（前锋/中场）：进球 + 助攻 + 胜率
  - 后场（后卫/门将）：胜率

### ⚡ 自动分队
- 按球员综合评分均衡分配
- 支持手动微调
- 实时显示两队平均评分

### 📝 赛后评分
- 比赛结束后，参赛队员可以给队友打分
- 管理员可以给所有球员打分
- 提交后自动重新计算综合评分

## 常见问题

**Q：真机预览报错「云函数调用失败」？**
A：确保云函数已部署，且AppID和云环境ID配置正确。

**Q：数据库查询慢？**
A：检查是否创建了索引（特别是 `matches.date` 和 `players.stats.rating`）。

**Q：图片上传失败？**
A：检查云存储权限，确保允许上传。
